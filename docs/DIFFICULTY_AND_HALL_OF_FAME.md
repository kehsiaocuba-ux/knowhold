# Grades, difficulty and the Hall of Fame (design, draft)

Knowhold is made for kids to play with their friends, and to make school learning more fun and more of a challenge.
So the questions follow the school grade, and the Hall of Fame (HOF) recognises how hard the game was.
This page is a draft: items marked **TBD** are still to be decided.

## Grades

Questions are written for a school grade: **2nd to 5th grade** (elementary), **6th to 8th** (middle school),
**9th to 12th** (high school), and **college** as the highest level. In code: `Grade` in
[`src/engine/levels.ts`](../src/engine/levels.ts).

The kind of knowledge should match the age, not only the difficulty. How each subject changes from grade to grade
will be written down in detail later (**TBD**).

## Difficulty

Four levels, from easiest to hardest: **easy, normal, hard, hardest**. "Hardest" is the top of the line.

Proposed meaning (**TBD**, to be refined for each grade):

| Level | Meaning |
|---|---|
| easy | Review of earlier material and simpler questions |
| normal | What the grade is expected to know |
| hard | Beyond the grade, needs real understanding |
| hardest | The top of the line: a real challenge for the grade |

## What is chosen before a game

Before the game, the players choose, like the turn limit:

- the **grade** (one for the whole game to start with),
- the **difficulty**,
- the **turn limit** (40, 80, 120 or a custom number).

All three are stored in the game state so the Hall of Fame can record them.

**TBD:** friends in different grades. The engine could pick questions by the grade of the player whose turn it is
(one grade per player instead of one per game).

## Hall of Fame

The aim: someone who wins on **hardest** should be recognised for it ("they did it in the hardest"),
and easy games should not compete with hard ones, because points are easier to get on easy.

- **One board for each combination of number of players, turn limit and difficulty.**
- The **grade** is saved with every entry and can be used to filter a board.
- Difficulty does **not** change the points. A harder level gets its own board, so there is no multiplier to argue about.
- An entry holds: nickname, grade, difficulty, number of players, turn limit, final points, turns played,
  how the game ended (bankruptcy or turn limit), and the date.
- Ranking inside a board: final points first, then fewer turns (**TBD**, current proposal).
- The test results (for example 50 Art questions) get the same treatment: one board per difficulty,
  with the speed and accuracy categories described in RULES.md section 11.

## Writing the questions

There are 8 subjects, 12 grade levels and 4 difficulties, which is **384 groups of questions**.
At 20 questions each that would be over 7,500 questions, so this has to grow step by step:

1. Start with one grade and a few subjects, at normal difficulty, and make the format and the game work.
2. Add difficulties and grades gradually.
3. Quick Math can be generated by code for each grade, so it does not need written questions.

Rules for the content:

- Questions are original, or come from openly licensed sources that allow it. The source and its license are recorded.
  Nothing is copied from commercial games or quiz sites.
- Every question is checked by a person for accuracy and for being suitable for children.
- Questions follow school standards as a reference for what each grade learns.

## Children's privacy

The game is for children, so it keeps the minimum of data:

- The Hall of Fame stores **nicknames only**: no real names, emails, accounts or locations.
- The first version keeps everything on the device, with no online accounts.
- If an online version is ever built, children's privacy laws must be checked first.
